About the blocklist

Purity Lock includes 76,747 domains derived from the StevenBlack hosts porn list and related sources. To update it manually, replace blocklist.json with a JSON array of domains, then reload the extension.

Updates take effect only after the extension is reloaded. A validated local cache keeps the last usable list available if loading fails.
